# proa_pediatrico_tecnologias
Creación de código para limpiar archivos en Excel.

## Requisitos

- Python 3.10+
- Dependencias en `requirements.txt`

## Uso rápido

```bash
python -m pip install -r requirements.txt
python -m src.proa_pediatrico_tecnologias.clean_excel /ruta/archivo.xlsx
```

El archivo limpio se guarda como `archivo_cleaned.xlsx` en la misma carpeta.
